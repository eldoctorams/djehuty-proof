# Roadmap

## Phase 0 — Evidence model
- Define claim, source, evidence-span, provenance and review-decision schemas.
- Define support labels, coverage metrics and uncertainty rules.

## Phase 1 — Deterministic alpha
- Markdown report and local-source ingestion.
- Atomic claim IDs, manual evidence linking and hash-based provenance.
- JSON/Markdown audit exports and citation coverage metrics.

## Phase 2 — Assisted verification
- Model-assisted claim segmentation and evidence retrieval.
- Support/contradiction suggestions with exact spans and reviewer override.
- CI gates and regression test corpus.

## Phase 3 — Interoperability
- Signed ledgers, source snapshots and plugin API.
- Research, OSINT and compliance profiles.

Release gates: traceable judgments, calibrated uncertainty, reviewer controls and reproducible fixtures.
