# Reference Projects and Gap Analysis

| Project | Strength to study | Opportunity for ClaimLedger |
|---|---|---|
| [dissent](https://github.com/BludIsosceles/dissent) | Checks whether citations support claims | Add a durable interoperable claim/evidence ledger |
| [Tessera](https://github.com/robert-vetter/tessera) | Evidence-grounded agent outputs | Support auditing existing reports and human review |
| [Open Evidence Standard](https://github.com/ydax/open-evidence-standard) | Evidence interoperability concepts | Specialize the model for exact claim-to-span decisions |
| [TRACE](https://github.com/ionsec/trace) | Traceability and provenance | Add report-level coverage, contradiction and CI gates |
| [OmniScientist V2](https://github.com/tsinghua-fib-lab/OmniScientist-V2) | Auditable research objects and workflows | Create a smaller tool usable outside a full research OS |

## Our wedge

Make every audit decision inspectable as claim → evidence span → source → provenance → reviewer decision. The product should expose uncertainty and allow deterministic re-audit.
